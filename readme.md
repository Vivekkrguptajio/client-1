🗂️ Columns Description
🔹 Daily Performance Data
Column Name	Description
Date	Date of the campaign data (DD-MM-YYYY)
Ad Spend (₹)	Total money spent on ads on that day
Impressions	Number of times ads were shown
Clicks	Number of clicks received
CTR (%)	Click Through Rate = (Clicks / Impressions) × 100
CPM (₹)	Cost per 1000 impressions
CPC (₹)	Cost per click
🔹 Campaign Data
Column Name	Description
Status	Campaign status (Active / Paused)
Name	Campaign name
Order (SKU)	Product identifier (2–3 digit numeric ID)
Bidding Strategy	Strategy used (Auto, Manual CPC, Maximize Clicks)
Campaign Subtype	Type of campaign (Search, Display, Shopping)
Budget Type	Budget type (Daily / Lifetime)
Creation Date	Date when campaign was created
Avg Daily Budget	Average daily budget allocated
Ad Spend (Campaign)	Total spend for the campaign
Ad Impressions	Total impressions for the campaign
Ad Clicks	Total clicks for the campaign
CTR (Campaign)	Campaign-level CTR
CPM (Campaign)	Campaign-level CPM
CPC (Campaign)	Campaign-level CPC
ROAS	Return on Ad Spend
Avg Time In Budget	Percentage of time campaign stayed within budget
